# World Troubles
The program aims for the biggest problem in the world. Lack of information

## Table of Contents
-Description
-Packages
-Usage

## Description
The program was created for hackathon 'student hacks'. Program is the solution for the global lack of information and disinformation.
It is simple to use, has links for proffesional website where people can get help

## Main packages
React.js, Tree.js, React Testing Library

## Usage
You can run program by typing 'npm run start' and then you have to press 'start' button.
